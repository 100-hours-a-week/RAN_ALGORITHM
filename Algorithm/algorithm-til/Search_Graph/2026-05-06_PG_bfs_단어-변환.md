## 🧩 문제 설명

`begin`에서 시작해서 `target`으로 바꾸려고 할 때,  
한 번에 한 글자만 바꿀 수 있고, 중간 단어는 `words`에 있는 단어만 사용할 수 있다.  
최소 몇 단계로 변환 가능한지 반환하고, 불가능하면 `0`을 반환한다.

---

## 🧩 문제 핵심 포인트

- 이 문제는 DP가 아니라 "최소 단계"를 찾는 최단거리 문제다.
- 단어 하나를 노드로 보고, 한 글자만 다른 단어끼리 간선으로 연결하면 그래프가 된다.
- 최소 변환 횟수는 BFS의 첫 도착 시점 거리로 바로 구할 수 있다.

---

## 💡 인사이트 : BFS 거리 관리 방식 2가지

- 방법 1. 큐에 거리(dist)를 함께 저장

  - 형태: `queue.append((node, dist))`
  - 특징:
    - 현재 노드와 현재까지의 **이동 횟수를 함께 관리**
    - 구현이 간단해서 코딩테스트에서 자주 사용
    - 단순 최단거리 BFS 문제에서 많이 사용

- 방법 2. distance 배열(dict)로 거리 관리
  - 형태: `distance[next] = distance[cur] + 1`
  - 특징:
    - **거리 정보를 별도로 저장**
    - 모든 노드까지의 최단거리 관리에 유리
    - 다익스트라/그래프 문제 스타일로 확장하기 좋음

## 💡 그래프 표현 방식

- 인접 리스트

  - 형태: `graph[node] = [연결 노드들]`
  - 메모리 효율이 좋아 대부분의 그래프 문제에서 자주 사용

- 인접 행렬
  - 형태: `graph[a][b]`
  - 두 노드 연결 여부를 즉시 확인 가능
  - 노드 수가 많으면 메모리 사용량이 커짐

## 🧩 내 풀이 방식 (주석 기반 사고 흐름)

- `# dp아님?`에서 시작해서, 최소 단계 문제라 BFS로 전환했다.
- `# bfs가 필요한것` 주석대로 3가지를 먼저 고정했다.
  - 큐(`queue`)
  - 방문 집합(`visited`)
  - 시작 노드(`begin`)
- `# 어떻게 map을 그릴지` 고민은 인접 리스트 구성으로 해결했다.
  - `hot : hit, dot` 같은 형태로 연결 정보를 저장
- 큐에 `(node, dist)`를 넣어 거리까지 함께 이동시키는 방식으로 구현했다.

## 🧩 코드 로직 정리

### 전체 흐름

```txt
1. can_diff(word1, word2)로 두 단어가 한 글자 차이인지 판별
2. words + begin 전체를 대상으로 인접 리스트(graph) 구성
3. queue = deque([(begin, 0)])로 BFS 시작
4. queue에서 (현재 단어, 거리) 꺼내기
5. 현재 단어가 target이면 거리 반환
6. 인접 단어 중 미방문 단어를 방문 처리 후 (다음 단어, 거리+1) 삽입
7. 끝까지 target을 못 찾으면 0 반환
```

---

## 🧩 코드 구현 (내 풀이)

```python
from collections import defaultdict
from collections import deque


def can_diff(word1, word2):
    count = 0

    for i in range(len(word1)):
        if word1[i] != word2[i]:
            count += 1

    return count == 1


def solution(begin, target, words):
    graph = defaultdict(set)
    visited = {begin}
    all_words = words + [begin]

    # 노드 연결하기: 인접 리스트로 만들기
    for word1 in all_words:
        for word2 in all_words:
            if can_diff(word1, word2):
                graph[word1].add(word2)
                graph[word2].add(word1)

    # 큐 안에 (노드, 거리)를 함께 넣어서 BFS 진행
    queue = deque([(begin, 0)])

    while queue:
        cur_node, dist = queue.popleft()

        if cur_node == target:
            return dist

        for next_node in graph[cur_node]:
            if next_node not in visited:
                visited.add(next_node)
                queue.append((next_node, dist + 1))

    return 0
```

---

## 🧩 사용된 Python 개념

- `defaultdict(set)` : 인접 리스트를 중복 없이 구성
- `deque` : BFS 큐의 `popleft()`를 `O(1)`로 처리
- `set` : 방문 여부를 빠르게 확인
- 튜플 큐 원소 : `(node, dist)` 형태로 거리 동시 관리

---

## 🧩 복잡도

- 시간복잡도 : `O(W^2 * L + E)`
  - `W`: 단어 개수, `L`: 단어 길이
  - 인접 리스트 구성에서 모든 단어 쌍 비교
- 공간복잡도 : `O(W + E)`

## ⚠️ 오답 포인트

- DFS로 풀면 최소 단계 보장이 바로 되지 않는다.
- 인접 리스트를 만들지 않고 매 단계 전체 words를 다시 비교하면 구현이 복잡해진다.
- 방문 체크가 없으면 같은 단어를 계속 탐색해 비효율/무한 루프 위험이 생긴다.
