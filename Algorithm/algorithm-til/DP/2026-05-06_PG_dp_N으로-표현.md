## 🧩 문제 설명

숫자 `N`과 사칙연산(`+`, `-`, `*`, `//`)만 사용해서 목표값 `number`를 표현할 때,  
`N`을 최소 몇 번 써야 하는지 구하는 문제다.  
`NN`, `NNN`처럼 숫자를 이어 붙인 형태도 허용되며, `N` 사용 횟수가 `8`을 넘으면 `-1`을 반환한다.

---

## 🧩 문제 핵심 포인트

- `N` 사용 횟수 `i`를 상태로 두고, 각 단계에서 만들 수 있는 모든 수를 `set`으로 관리한다.
- `dp[i]`는 `N`을 정확히 `i`번 사용해서 만들 수 있는 값들의 집합이다.
- `i`개를 만드는 방법은:
  - 이어붙인 수 `int(str(N) * i)` 1개
  - `j`개로 만든 값과 `i-j`개로 만든 값을 사칙연산으로 조합한 값
- 작은 `i`부터 검사하므로 `number`를 처음 발견한 `i`가 곧 최소 사용 횟수다.

---

## 🧩 내 풀이 방식

- `dp = [set() for _ in range(9)]`로 `1~8`회 사용 케이스를 저장한다.
- 각 `i`마다 먼저 `N`, `NN`, `NNN` 형태를 추가한다.
- `j=1..i-1` 분할로 `(dp[j], dp[i-j])`의 모든 조합을 계산한다.
- 연산은 `+`, `-`, `*`, `//`를 수행하고, 나눗셈은 `b != 0`일 때만 처리한다.
- 각 `i` 단계가 끝날 때 `number in dp[i]`면 즉시 `i`를 반환한다.

---

## 🧩 코드 로직 정리

### 전체 흐름

```txt
1. N == number 이면 1 반환
2. dp[1..8] 집합 초기화
3. i = 1..8 반복
4. 이어붙인 수(int(str(N) * i))를 dp[i]에 추가
5. j = 1..i-1 분할
6. a in dp[j], b in dp[i-j] 조합으로 사칙연산 결과 추가
7. number가 dp[i]에 있으면 i 반환
8. 끝까지 못 찾으면 -1 반환
```

---

## 🧩 코드 구현 (내 풀이)

```python
def solution(N, number):
    if N == number:
        return 1

    # dp[i] = N을 i번 써서 만들 수 있는 수들
    dp = [set() for _ in range(9)]

    for i in range(1, 9):
        # 5, 55, 555 같은 수
        dp[i].add(int(str(N) * i))

        for j in range(1, i):
            for a in dp[j]:
                for b in dp[i - j]:
                    dp[i].add(a + b)
                    dp[i].add(a - b)
                    dp[i].add(a * b)

                    if b != 0:
                        dp[i].add(a // b)

        if number in dp[i]:
            return i

    return -1
```

## 🧩 사용된 Python 개념

- `set` : 중복 제거 + 빠른 포함 여부 확인
- 리스트 컴프리헨션 : `dp` 상태 배열 초기화
- 중첩 반복문 : 상태 조합 완전 생성
- 정수 나눗셈 `//` : 문제 조건(나머지 버림) 반영

---

## 🧩 복잡도

- 시간복잡도 : `O(Σ(i=1..8) Σ(j=1..i-1) |dp[j]| * |dp[i-j]|)`
- 공간복잡도 : `O(Σ(i=1..8) |dp[i]|)`

`i <= 8`로 고정된 문제라 실제 실행은 제한된 범위 내에서 동작한다.

## ⚠️ 오답 포인트

- `N == number` 예외를 먼저 처리하지 않으면 최소값 1을 놓칠 수 있다.
- `dp[i]`를 리스트로 관리하면 중복이 폭증해 비효율적이다.
- `a // b`에서 `b == 0` 체크를 빼먹으면 런타임 에러가 난다.
- `i`를 큰 값부터 탐색하면 "최소 횟수" 조건을 보장할 수 없다.
