# for vs while

|        | for              | while                 |
| ------ | ---------------- | --------------------- |
| 언제   | 거칠 값이 정해짐 | 다음 값이 그때 정해짐 |
| i 조종 | 못 함 (읽기용)   | 직접 함               |
| 점프   | 규칙적이면 가능  | 불규칙도 가능         |
| 주의점 | —                | 무한 루프             |

## for — 다음 값이 정해져 있을 때

range, 리스트, 문자열처럼 **돌 값이 미리 정해진** 경우에 써요.

```python
for i in range(1, 5):   # 1, 2, 3, 4 (미리 정해짐)
    print(i)

for x in [10, 3, 7]:    # 리스트 원소 순서대로
    print(x)
```

- `i`는 **읽기용**. 안에서 `i`를 바꿔도 다음 반복에 덮어써짐 → 반복문 블록 안에서 다음 계단을 정해줘도 의미 없음
- 무조건 for문에 정해져있는 다음증감값으로 이동

---

## while — 다음 값이 그때그때 정해질 때

다음 값이 **조건에 따라 달라지거나**, 언제 끝날지 미리 모를 때 써요.

```python
i = 1
while i <= 20:
    print(i, end=" ")
    if i % 2 != 0:   # 홀수면
        i *= 2
    else:            # 짝수면
        i += 3
```

- `i`를 내가 직접 정할수있다. → **불규칙한 점프 가능**
- "조건이 풀릴 때까지" 반복할 때 (예: 입력이 0이 될 때까지)

**무한 루프 주의** — `i`를 바꾸는 걸 빼먹거나 조건이 안 끝나면 영영 안 멈춤.
짤 때마다 _"이 루프 언젠가 끝나긴 하나?"_ 한 번씩 확인하기.
